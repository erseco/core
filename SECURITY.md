# Security policy

## Supported versions

The latest stable `@schemd/core` release receives security fixes. Older documentation
lines remain available for reference; they are not a promise of security maintenance.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/schemd/core/security/advisories/new)
from this repository's Security tab. If that route is unavailable, email
[sirneij@gmail.com](mailto:sirneij@gmail.com) with the subject `Schemd security report`.
Please do not disclose an unpatched vulnerability in a public issue or discussion.

Include the affected version or commit, a minimal reproduction, the observed impact, and any
relevant runtime details. Reports concerning malicious compiler input, generated SVG, resource
exhaustion, or the website's compilation endpoint are welcome. Remove credentials and private
user data from examples.

The maintainer aims to acknowledge a report within seven days and agree on the next update with
the reporter. This volunteer project cannot guarantee a remediation deadline. The report remains
private while a fix and coordinated disclosure are arranged. Confirmed fixes should include a
regression test and an advisory when appropriate.
