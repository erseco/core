# Support

Ask usage and design questions in [Schemd Discussions](https://github.com/schemd/core/discussions).
Search existing discussions and issues before starting a new one.

Report reproducible defects in [this repository's issue tracker](https://github.com/schemd/core/issues/new/choose).
Include the package version or commit, a minimal input, what you expected, and what happened.
For the website, include the route, interface language, browser, and relevant viewport details.

Compiler syntax, routing, and SVG issues belong in [schemd/core](https://github.com/schemd/core/issues).
Documentation, the IDE, translations, and laboratories belong in
[schemd/web](https://github.com/schemd/web/issues). CircuiTikZ conversion belongs in
[schemd/circuitikz](https://github.com/schemd/circuitikz/issues).

Use [SECURITY.md](./SECURITY.md) for vulnerabilities and
[CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) for private conduct reports.
Support is provided by volunteers; response and implementation dates are not guaranteed.
